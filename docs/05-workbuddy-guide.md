## 什么是 WorkBuddy

WorkBuddy 是腾讯推出的全场景职场 AI 智能体桌面工作台。您只需用一句话描述需求，WorkBuddy 便能像同事一样自主规划和执行复杂任务，并交付可验收的结果。

![]({{ site.baseurl }}/assets/img/1.webp)

WorkBuddy 面向的是完整的工作任务。

它的核心能力可以概括为三点，听得懂人话，能够自主思考规划，也真的能够操作电脑交付成果。


## AI 工作系统

先看全景：一次 AI 任务里发生了什么

![]({{ site.baseurl }}/assets/img/2.webp)

这张图可以用一句话解释：模型负责理解和生成，Agent 负责围绕目标组织行动，Skill 提供专业方法，工具与 MCP/API 让行动触达真实世界，人负责边界与验收。

把一次真实任务拆开看，信息大致这样流动：

你提出一个目标 → Agent 把它拆成几步 → 遇到专业子任务就加载对应的 Skill，遇到要碰外部系统就调用工具 → 工具通过 MCP 或 API 真正读写数据库、发消息、改文件 → 结果回到模型，模型判断下一步 → 你做边界把控和最终验收。

五类角色里，模型是大脑，Agent 是调度员，Skill 是专家手册，工具与接口是手脚，**人是裁判**。


## 各区域功能简介

![]({{ site.baseurl }}/assets/img/3.webp)

| **区域**  | **功能**                           |
| ------- | -------------------------------- |
| **侧边栏** | 显示任务列表（按文件夹分组），支持搜索和管理。底部显示用户头像。 |
| **对话区** | 核心交互区域，包含任务标题栏、消息列表和输入框。         |
| **结果区** | 右侧面板，展示产物、全部文件、变更、预览等视图。         |

侧边栏的“任务”和“工作空间”的区别，在于你是否设置了“工作空间”目录。

“工作空间”是 WorkBuddy 为了管理任务而设置的目录，每个任务都有一个对应的目录空间，任务可以在目录空间内进行操作。

若未设置，会在默认安装的目录下执行任务，对话保存在“任务”目录下。

### 3.4 资料库

> 从超级个体到超级团队，让产物沉淀、管理、流转协同。

资料库是人和 Agent 共同的产物存放地。它让 AI 生成的文件从"用完即散落"，推进到"沉淀、管理、流转协同"的完整工作链路：Agent 产出的文档自动归位，团队资料集中在同一棵目录树，任务可以随时把资料库中的内容读进来继续加工，做好的页面还能变成别人也能打开的链接。

资料库与普通网盘的区别在于：它不是把文件堆在一起，而是让 MD、CSV、HTML 三种载体互相引用、彼此联动——文档被页面引用、表格被页面渲染，改一处、处处生效。

### 3.9 自媒体运营

![]({{ site.baseurl }}/assets/img/8.webp)

#### 一、文档说明

本文介绍如何借助 `WorkBuddy` 完成自媒体内容策划、文案撰写与视频素材整理，适用于小红书、短视频等内容生产场景。

#### 二、小红书内容生成

* **适用场景**：需要快速产出标题、正文、封面文案或选题方向。
* **推荐做法**：一次说明账号定位、受众人群、语气风格与内容目标。
* **示例指令**：

> 请根据我提供的产品卖点，帮我写 `3` 个适合小红书发布的选题，并为其中 `1` 个选题生成标题、正文、话题标签和封面文案，语气自然、真实、适合种草场景。

![]({{ site.baseurl }}/assets/img/9.png)

#### 三、视频内容生成

* **适用场景**：需要将脚本、口播文案、镜头分镜或视频说明快速整理出来。
* **推荐做法**：说明视频时长、平台类型、目标受众与输出形式。
* **示例指令**：

> 请帮我生成一份 `60` 秒短视频脚本，包含开头钩子、口播文案、镜头建议和结尾行动引导，整体节奏适合信息密度较高的内容账号。

![]({{ site.baseurl }}/assets/img/10.png)

#### 四、使用建议

* **先定平台，再写内容**：不同平台的内容结构和节奏差异较大。
* **明确人群与风格**：能显著提升文案贴合度。
* **先出初稿，再做微调**：标题、封面、标签和正文建议分轮优化。

本文介绍如何使用 `WorkBuddy` 完成表格可视化、数据搜集与报告生成，适用于经营分析、项目汇报、市场调研与业务复盘等场景。

#### 二、将 `Excel` 表格转为可视化图表

#### 三、搜集数据并生成可视化报告

##### 1）描述数据需求

当数据尚未整理成文件，或需要从网络、多个来源搜集信息时，可直接描述数据主题、范围和来源偏好。

**示例指令**：

> 请帮我搜集近 `1` 年国内 `AI` 办公工具相关的市场信息，重点关注用户规模、应用场景和代表产品，并整理成结构化数据。

##### 2）描述报告要求

建议同时说明报告格式、章节结构、图表偏好与汇报对象。

**示例指令**：

> 请基于搜集到的数据生成一份可视化分析报告，包含核心结论、关键数据图表、趋势判断和行动建议，适合管理层阅读。

##### 3）输出结果

`WorkBuddy` 会完成数据搜集、分析、绘图与报告排版，输出完整结果文件。

#### 四、使用建议

* **先明确分析问题**：先说清要回答什么业务问题，再决定图表形式。
* **避免一次提过多要求**：建议先产出基础版本，再逐轮补充图表与结论。
* **说明数据可信度要求**：如需公开来源、出处链接或时间范围，建议提前写明。


## 注意事项

当上下文已使用超过50%时：需要清理记忆，否则会降智。

WorkBuddy 清理上下文有几种方式，按「彻底清空 → 压缩保留 → 开新会话」三档给你梳理：

### 1. 彻底清空当前对话：`/clear` 或 `/清除上下文`

* 效果：直接清空当前会话的全部上下文，AI「忘记」之前聊过的内容，从头开始。
* 适合场景：一个话题已聊完、要切到完全无关的任务、或对话变长导致回复变慢变糊涂时。
* 提醒：清空后无法恢复该对话的历史，重要结论请先导出或存档。

### 2. 压缩而非删除：`/compact`

* 效果：把当前上下文交给模型主动总结，用精简摘要替换原始对话，腾出窗口继续跑。
* 适合场景：任务还没跑完、但对话已很长、模型开始变慢或漏要求，又不想开新会话。
* 注意：压缩不是完全无损，部分细节/特殊约束可能被弱化。复杂任务压缩前，建议先让 Agent 整理一份「任务检查点」（当前目标、已完成、关键约束、未解决问题、下一步），写入工作区文件再 `/compact`，这样新一轮仍能读回状态。

### 3. 开新会话：`/new` 或 `/新建对话`

* 最干净的方式——直接另起一个独立会话，旧上下文完全不带入。
* 还有一个相关命令：`/导出对话` 可先把当前记录存下来再清。

### 4. Max 模式开关（自动压缩行为）

* 在模型选择下拉顶部：
  * **开 Max**：不压缩，保留完整上下文，适合需要长期记忆的复杂任务（但更费积分）。
  * **关 Max**：WorkBuddy 会在窗口接近上限时自动帮你压缩上下文。
* 任务相对独立、或已积累大量不再重要的讨论时，关掉 Max 通常更合适。

### 5. 顺手减负（长期 Token 优化）

* 在任务栏手动删除没用的旧任务对话；
* 让 WorkBuddy 帮你整理/删除工作区里不再需要的中间产物文件，避免长时间加载旧任务消耗 Token。


几个实用命令速查：`/clear` 清空上下文 · `/compact` 压缩上下文 · `/new` 新建对话 · `/status` 看会话状态 · `/task` 看任务列表。
